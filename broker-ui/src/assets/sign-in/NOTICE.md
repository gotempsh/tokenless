# Identity provider logos

The SVG files in this directory identify the identity provider a sign-in
button leads to. Each logo is a trademark of its owner, used only to identify
that provider; no endorsement is implied. `<key>.dark.svg` is the variant for
dark backgrounds, the same artwork in white.

Providers not recognised from their issuer are shown with the OpenID logo.

## Simple Icons

- Source: https://github.com/simple-icons/simple-icons (version 16.37.0)
- Licence: CC0 1.0 Universal (public domain dedication), except where noted
- Logos: auth0, authentik, gitlab, google, keycloak, okta, openid
- Each path is filled with the brand colour Simple Icons records for it.
- Keycloak: Simple Icons records its licence as the Linux Foundation's
  trademark usage guidelines (https://www.linuxfoundation.org/legal/trademark-usage),
  under which it is used here to refer to the Keycloak project.

## Microsoft

- `microsoft.svg` is drawn here: four coloured squares, the Microsoft logo,
  used to identify Microsoft Entra ID.
